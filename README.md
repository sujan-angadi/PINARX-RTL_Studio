# RTL Studio
### By PINARX

**Version:** 1.0

RTL Studio is a modern RTL development environment for designing, simulating,
synthesizing, and visualizing Verilog designs.

It provides a unified graphical environment around open-source EDA tools
including Icarus Verilog, GTKWave, Yosys, and Graphviz.

---

# 1. Features

- Verilog RTL editing
- Syntax highlighting
- Bracket matching
- Project management
- File explorer
- Icarus Verilog compilation
- Verilog simulation
- GTKWave waveform viewing
- VCD waveform generation
- Yosys RTL synthesis
- Graphviz schematic visualization
- Design hierarchy analysis
- Design statistics
- Generic synthesis cell statistics
- Design & PPA dashboard
- Integrated EDA tool detection
- Linux desktop integration

---

# 2. Supported Platform

RTL Studio v1.0 is released for:

- Linux x86_64

### Tested Environment

RTL Studio v1.0 has been tested on:

- Rocky Linux 10.2
- x86_64
- GNOME Desktop

RTL Studio is expected to work on other modern x86_64 Linux distributions,
but compatibility may vary depending on the distribution, desktop environment,
libraries, and external EDA tool environment.

The included EDA installer currently supports:

- Linux
- x86_64 / amd64

---

# 3. Requirements

RTL Studio uses the following external EDA tools:

| Tool | Command | Purpose |
|---|---|---|
| Icarus Verilog | `iverilog`, `vvp` | Verilog compilation and simulation |
| GTKWave | `gtkwave` | Waveform viewing |
| Yosys | `yosys` | RTL synthesis |
| Graphviz | `dot` | Schematic visualization |

These tools are NOT bundled inside the RTL Studio application.

RTL Studio provides a separate installer that installs the required tools
through the OSS CAD Suite.

---

# 4. INSTALLATION

The easiest installation method is:

```text
STEP 1 → Install EDA Tools
STEP 2 → Install RTL Studio
STEP 3 → Launch RTL Studio
```
